# 강연례 AI 강사 소개 페이지 (강의용 샘플)

33년 현장 경험의 AI 강사 강연례를 소개하는 한 페이지짜리 웹사이트입니다.
HTML·CSS·JavaScript만 사용하며, 설치나 빌드가 필요 없습니다.

- 사이트: https://kang-yeonrye-home.netlify.app
- 저장소: https://github.com/yunyaekang/kang-yeonrye-home
- GitHub `main`에 올리면 Netlify가 자동으로 다시 배포합니다.

## 파일 구조

| 파일 | 하는 일 |
|---|---|
| `index.html` | 페이지 내용 (글·사진·버튼) |
| `css/style.css` | 색상·글꼴·배치 등 디자인 |
| `js/main.js` | 햄버거 메뉴, 이메일 조합, 숫자 올라가기, 타이핑, 스크롤 효과 |
| `images/` | 사진 (`profile.jpg`, `activity-1~3.jpg`, `preview.jpg`) |
| `netlify.toml` | Netlify 배포 설정과 보안 헤더 |

## 미리 보기

`index.html` 파일을 더블클릭하면 브라우저에서 열립니다.

## 샘플 내용 바꾸기

강의용 샘플이라 아래 내용은 임시 값입니다. 실제 정보로 바꿔 주세요.

- 전화번호 `010-1234-5678` (`index.html`에서 `tel:01012345678`도 함께)
- 이메일 `hello@example.com` (`data-user`, `data-domain` 값)
- 유튜브 주소, 사무실 주소
- 경력 숫자 중 '(샘플)' 표시된 항목
- `images/` 안의 사진 (같은 파일 이름으로 바꿔 넣으면 됩니다)
